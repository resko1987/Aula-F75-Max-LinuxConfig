# AULA F75 Max — настройка под Linux через keyd

Возвращает обычные клавиши **F1–F12** на клавиатуре **AULA F75 Max** (2.4G-донгл `05ac:024f`)
в Linux и добавляет переключение между режимами **«F-клавиши»** и **«медиа-клавиши»** по **FN + Esc**.

Работает через [keyd](https://github.com/rvaiya/keyd) — сторонний драйвер не нужен
(официальная утилита захардкодила переключение F-режима и не дружит с Linux).

## Что делает

Клавиатура шлёт на верхнем ряду медиа-коды вместо F-клавиш, а FN передаётся как
`KEY_RIGHTCTRL` (поэтому FN+буква давала Ctrl+буква и закрывала окна). Этот конфиг:

- возвращает верхнему ряду **F1..F12** по умолчанию;
- добавляет **медиа-режим** (яркость, громкость, mute, управление треками) по **FN + Esc**;
- убирает отправку Ctrl с клавиши FN.

## Установка

```bash
git clone https://github.com/<вы>/Aula-F75-Max-LinuxConfig.git
cd Aula-F75-Max-LinuxConfig
sudo ./install.sh
```

Скрипт ставит `keyd`, копирует `keyd/aula-f75.conf` в `/etc/keyd/` и запускает демон.

## Использование

| Действие | Результат |
|----------|-----------|
| **FN + Esc** | переключение режимов: F-клавиши ⇄ медиа-клавиши |
| F-режим: **F1..F12** | обычные F-клавиши (F5 = обновить страницу и т.д.) |
| Медиа-режим: **F1/F2** | яркость вниз/вверх |
| Медиа-режим: **F7/F9** | предыдущий/следующий трек |
| Медиа-режим: **F8** | играть/пауза |
| Медиа-режим: **F10** | выключить звук |
| Медиа-режим: **F11/F12** | громкость вниз/вверх |

> FN — клавиша рядом с правым Alt; система видит её как `rightcontrol`.

## Файлы конфигурации

Смотрите [`keyd/aula-f75.conf`](keyd/aula-f75.conf). Устройство матчится по id `05ac:024f`
(2.4G-донгл представляется как *Apple Aluminium Keyboard (ANSI)*).

## Как найти id устройства

`05ac:024f` — это USB-идентификатор `vendor:product` 2.4G-донгла (он представляется как
*Apple Aluminium Keyboard (ANSI)*). Найти свой можно командой:

```bash
lsusb
```

Пример вывода:

```
Bus 001 Device 003: ID 05ac:024f Apple, Inc. Aluminium Keyboard (ANSI)
```

Указывайте `<vendor>:<product>` (например `05ac:024f`) в секции `[ids]` — префиксом он
совпадает со всеми тремя интерфейсами донгла (клавиатура/мышь/мультимедиа). Это же id
keyd печатает в логах как `DEVICE: match 05ac:024f:...`.

## Откат

```bash
sudo ./uninstall.sh
```

Полное удаление keyd:

```bash
sudo systemctl disable --now keyd
sudo apt purge keyd
```

## Отладка

- Имена клавиш в keyd 2.5.0: используйте `rightcontrol`/`leftcontrol` (не `rightctrl`).
- Проверка, что конфиг загрузился и донгл совпал:

  ```bash
  journalctl -u keyd -n 30 --no-pager
  ```

  В журнале должно быть:

  ```
  CONFIG: parsing /etc/keyd/aula-f75.conf
  DEVICE: match    05ac:024f:...  /etc/keyd/aula-f75.conf  (2.4G Dongle)
  ```

- Если игнорируются все устройства: демон мог стартовать до создания конфига —
  просто выполните `sudo systemctl restart keyd` ещё раз.
